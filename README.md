# github_page
## Criando site do portifólio:  

Para sua criação foi utilizado um template Bootstraps.  
Utilizando o GitHub Pages uma página da web é foi criada com o intuito de servir como meu portifólio porfissional.  
E este repositório serve para a criação do site do portifólio profissional.  
Nesse repositório contêm todos os arquivos html e o css, como também todas as imagens que foram usadas ou vieram com o template.  
  
#### assets:  

Contém as imagens/documentos utilizados e assets do template.  
  
#### css:  
Contém o arquivo de estilo da página (css).  
  
#### js:  
Espaço para a implementação de Javascript, mas que ainda não foi utilizado.  
  
#### Arquivos html:  
Armazenam os códigos das páginas web do site.
